# ProjectFlow

**ProjectFlow** — веб-приложение для управления проектами и задачами на Kanban-досках с синхронизацией изменений в реальном времени.

## Возможности

- **Авторизация** — доступ к приложению с использованием access token.
- **Управление досками** — получение списка досок, просмотр отдельной доски, создание, редактирование и удаление.
- **Kanban-доски** — организация задач по колонкам.
- **Управление задачами** — создание, редактирование и удаление задач.
- **Перемещение задач** — изменение колонки и позиции задачи с сохранением через API.
- **Dashboard** — статистика по проектам и задачам, список недавно созданных досок.
- **REST API** — взаимодействие с backend для получения и изменения данных.

## Технологический стек

**Frontend:** React, TypeScript, Vite, Zustand, TanStack Query, SCSS
**Backend:** Node.js, Express, PostgreSQL
